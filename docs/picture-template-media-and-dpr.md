# Responsive Images in Breakpoint Images

## Overview

Breakpoint Images renders responsive images with standard HTML image elements:

- `<picture>`
- `<source>`
- `<img>`

Each image is generated from your configured breakpoints and formats. The browser then chooses the correct source for the current viewport and device pixel density.

## How Rendering Works

For each configured breakpoint, the plugin generates one primary source and, when enabled, one secondary source.

- Primary source: main output format
- Secondary source: fallback format
- Final `<img>`: fallback image element

This output is generated by the plugin picture template at:

- `src/templates/picture.twig`

## Breakpoint Media Behavior

Breakpoint values are normalized and ordered, then converted into contiguous media ranges.

The generated source set uses:

- `max-width` ranges for non-final enabled breakpoints
- `min-width` for the final enabled breakpoint

This creates continuous viewport coverage for source selection.

## DPR Source Set Behavior

Inside each selected source, the plugin generates DPR candidates in `srcset` using density descriptors.

- `1x` is always present
- Additional configured ratios are added (for example `2x`, `3x`)

Browsers use these candidates to select sharper assets on higher-density displays.

## Configuration Surface

The user-facing settings relevant to this behavior are:

- Breakpoints
- Format
- Secondary Format
- DPR ratios

The default breakpoint map includes values such as `xs`, `sm`, `md`, `lg`, `xl`, and `2xl`.

## Standards Alignment

This implementation uses standard responsive image behavior based on `picture/source/img` and `srcset` density descriptors.
